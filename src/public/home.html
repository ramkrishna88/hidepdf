Hide secrets in PDFs — for real

HidePDF Content finds emails, phones, cards, names, addresses, and country IDs, then burns them out of the page. Hidden text is removed, so those values cannot be copied or extracted from the download.

Open playground API reference

What we hide

  • Emails, phone numbers, credit cards, and IBANs
  • Labeled names and addresses
  • Country IDs such as India Aadhaar, PAN, UPI, and US SSN
  • Amounts only if you choose to hide them

Scanned pages with little or no text are read with OCR before the hide list is shown. Uploads are not stored after the request.

Ways to use it

  • Playground — review fields in the browser, no key required
  • API — inspect, then hide, or hide in one POST /v1/redact call
  • Zapier — connect a HidePDF key and hide secrets from a public PDF URL

There is no customer login. API keys are issued to callers. This product is separate from TableJSON, which extracts tables into JSON. Contact: hello@hidepdfcontent.com.
