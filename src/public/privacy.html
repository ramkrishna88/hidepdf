Privacy

Last updated: 19 September 2026

HidePDF Content processes PDFs you send to hidepdfcontent.com so we can find sensitive fields and return a hidden file or a review list. This page explains what that involves.

Files you upload

Playground and API requests send the PDF to our server for that request only. We read the file to detect fields, optionally run OCR on sparse pages, and return inspect JSON or a burned PDF. Uploads are not kept as a document library after the request finishes.

What we look at

Detection looks for emails, phones, cards, IBANs, labeled names and addresses, and country IDs. Inspect responses show masked previews so you can review fields before hide. The hide step burns selected values out of the page images and strips extractable text for those values.

Accounts and keys

The public playground on this site does not need an API key. Direct API use requires a key you configure. We do not sell upload contents. Server logs may include request time, status, and size for reliability.
