About HidePDF Content

Updated 28 October 2026

HidePDF Content is a one-person project run by the operator of hidepdfcontent.com. The way to reach the operator is the contact page. There is no separate product company, no customer login, and no support desk hiding behind a ticket form.

Why it exists

People keep "redacting" a PDF by drawing a black rectangle in Preview, Word, or a browser extension. The page looks clean. The email, salary, or national ID is still in the file, and anyone who selects the box, or runs a text extractor, can read it. That failure mode is common enough that it needed a small tool aimed at it, not another editor with a highlighter.

HidePDF Content takes a different route. It finds likely secrets, lets you review the list, paints a dark block over the ones you keep checked, and rebuilds every page as a picture in a new PDF. The old text layer is not copied across. Before the file is returned, the server reads the result back and refuses to send it if a value it just hid is still extractable as text. The black-box guide shows the difference with a file you can try yourself.

The site started as a playground for that job and an API for the same job from another app. It is deliberately narrow. It does not edit paragraphs, sign documents, or merge files. If you need a general PDF editor, this is the wrong product.

Who it is for

The playground is for a person who has one PDF and needs to send it somewhere today: a payslip for a recruiter, a bank statement for a letting agent, an invoice with a phone number and a tax ID in the header. The API and the Zapier action are for someone who already has a key and wants the same burn step on a file they host at a public URL. Keys are issued by email. The website itself does not ask you to create an account.

This product is separate from TableJSON, which extracts tables into JSON. They share a contact address only in the sense that both are small tools from the same operator. They do not share uploaded files.

What the tool will and will not claim

It looks for emails, phone numbers, card numbers, IBANs, a set of country IDs (India Aadhaar, PAN, UPI, GSTIN, and IFSC; US SSN and ITIN; and others listed in the API reference), plus names and addresses when they sit on a labeled line such as "Bill to" or "Address". Amounts stay visible unless you tick them. Scanned pages with almost no text are read with OCR first. Details and the awkward cases are in the guides.

It will miss a name written in the middle of a sentence, a handwritten note, and a number in a shape the patterns do not know. The download is a picture of the pages, so text you left visible is still readable by eye and can be OCR'd again by someone else. It is not a certified redaction product for a court or a regulator. You review the list and the preview. The terms say the same thing in plainer legal language, and the privacy page says what happens to the upload (short version: memory for the request, not a library).

How to reach the person who runs it

Use the contact page. The form opens your email app and does not store the message on this server. Privacy requests, API key requests, and notes that the preview looks wrong all go there. Do not attach a live ID, card, or full bank statement. Describe the page instead.
