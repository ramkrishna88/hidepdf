The service

The API does the same job with a key. Guides, docs, and sample files are there to explain the limits. The site may show ads through Google AdSense, as described in the privacy page.

No promise that every secret is found

Detection is best-effort pattern matching. Review the field list and the preview before you share the download. Amounts stay visible unless you choose them. A name in a sentence, handwriting, and odd account formats are often missed. The download is a picture of the pages, so text you did not cover is still readable and can be OCR'd by someone else. If a rule tells you how redaction must be done for a filing, follow that rule. This is not a certified redaction product.

If you leave every box unchecked and download, the playground gives you the original file back. That is not a hidden file. Read the status line.
